title: Erstattung ohne Bescheid von Hand erfassen
requirement-type: functional
acceptance-criteria:
  - Ein Erstattungsbetrag von 0 EUR oder mehr wird als gültig angenommen; leere, ungültige oder negative Eingaben werden abgelehnt.
  - Nach der manuellen Eingabe folgt der Status aus dem Betrag (0 = Abgelehnt, weniger als eingereicht = Teilweise erstattet, sonst Erstattet).
  - Die manuelle Erstattung ist nur für eingereichte Einreichungen möglich, nicht im Status Erfasst.

Die Erstattung einer bereits eingereichten Einreichung kann ohne Bescheid von Hand eingetragen und später geändert werden; der Status folgt daraus automatisch.
